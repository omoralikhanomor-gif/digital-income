# Digital Income – BUY • SELL • EARN (Flutter Android App)

ডিজিটাল ইনকাম (Digital Income) মার্কেটপ্লেস অ্যাপের সম্পূর্ণ Flutter Android সোর্স কোড।

---

## 📱 কম্পিউটার ছাড়া শুধু মোবাইল দিয়ে বিনামূল্যে APK তৈরি করার নিয়ম (Step-by-Step)

আপনার কাছে যদি ল্যাপটপ বা কম্পিউটার না থাকে, তবুও আপনি শুধু আপনার অ্যান্ড্রয়েড ফোনের ব্রাউজার (Chrome) ব্যবহার করে **GitHub Actions**-এর মাধ্যমে সম্পূর্ণ বিনামূল্যে অফিশিয়াল রিলিজ APK ফাইল বিল্ড এবং ডাউনলোড করতে পারবেন।

### ধাপ ১: GitHub অ্যাকাউন্ট খোলা ও নতুন Repository তৈরি করা
1. আপনার মোবাইলের Chrome ব্রাউজারে **github.com**-এ যান এবং সাইন ইন করুন (না থাকলে ফ্রিতে অ্যাকাউন্ট খুলুন)।
2. Chrome ব্রাউজারের উপরে ৩-ডটে ট্যাপ করে **"Desktop site"** চালু করুন।
3. ডানপাশের **`+`** আইকনে ট্যাপ করে **"New repository"** চাপুন।
4. Repository name দিন: `digital-income-app`।
5. **Public** অথবা **Private** সিলেক্ট করে নিচে **"Create repository"** বাটনে ট্যাপ করুন।

### ধাপ ২: ফাইল আপলোড করা
1. এই অ্যাপের "মোবাইল APK বিল্ডার" থেকে **Download Project Zip** বাটনে ট্যাপ করে ফাইলগুলো ডাউনলোড করুন অথবা কপি করুন।
2. গিটহাব রিপোজিটরির পাতায় **"uploading an existing file"** অথবা **"Add file > Create new file"** অপশন ব্যবহার করে ফাইলগুলো যোগ করুন:
   - `pubspec.yaml`
   - `lib/main.dart`
   - `.github/workflows/build_apk.yml`
3. নিচে **"Commit changes"** বাটনে ট্যাপ করুন।

### ধাপ ৩: অটোমেটিক APK তৈরি ও ডাউনলোড
1. গিটহাব রিপোজিটরির উপরের মেনু থেকে **"Actions"** ট্যাবে ক্লিক করুন।
2. বামপাশে **"Build Digital Income Android APK"** দেখতে পাবেন।
3. **"Run workflow"** বাটনে চাপ দিন (অথবা আপনি কোনো কোড পুশ করলে এটি স্বয়ংক্রিয়ভাবে শুরু হবে)।
4. ৩ থেকে ৪ মিনিটের মধ্যে ক্লাউড সার্ভার সম্পূর্ণ অ্যান্ড্রয়েড APK বিল্ড করে সবুজ টিক মার্ক দেখাবে।
5. বিল্ডে ট্যাপ করুন এবং নিচে **Artifacts** সেকশনে **`Digital-Income-Release-APK`** দেখতে পাবেন।
6. ট্যাপ করলেই আপনার মোবাইলে `app-release.apk` ডাউনলোড হয়ে যাবে! এবার সরাসরি মোবাইলে ইন্সটল করে চালিয়ে দেখুন।

## 🚀 Codemagic ব্যবহার করার নিয়ম (বিকল্প পদ্ধতি)
1. মোবাইলে **codemagic.io**-তে যান এবং আপনার GitHub দিয়ে লগইন করুন।
2. আপনার `digital-income-app` রিপোজিটরিটি সিলেক্ট করুন।
3. প্রজেক্টের রুট ডিরেক্টরিতে ইতোমধ্যে রাখা `codemagic.yaml` ফাইলের কারণে স্বয়ংক্রিয়ভাবে Flutter Android ডিটেক্ট করবে।
4. **"Start new build"** চাপলেই Codemagic ক্লাউডে APK তৈরি করে সরাসরি আপনার ইমেইলে (`omoralikhanomor@gmail.com`) ডাউনলোড লিংক পাঠিয়ে দেবে!

- **বাংলাদেশ ব্যাংক MFS গাইডলাইন**: বিকাশ, নগদ বা রকেটের মার্চেন্ট এপিআই ব্যবহারের জন্য ভেরিফায়েড মার্চেন্ট অ্যাকাউন্ট প্রয়োজন।
